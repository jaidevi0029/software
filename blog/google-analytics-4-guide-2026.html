Google Analytics 4 Guide 2026: Track Your Website Traffic Like a Pro

May 13, 2026 11 min read 4,234 views

Google Analytics 4 (GA4) is the newest version of Google's analytics platform. It's completely different from Universal Analytics. This guide will teach you how to set up GA4, track important events, and understand your website traffic.

What is Google Analytics 4?

GA4 is an event-based analytics platform. Unlike the old version (Universal Analytics) which tracked sessions, GA4 tracks every interaction as an event. This gives you more detailed data about how users behave on your site.

Step 1: Create a GA4 Property

Go to analytics.google.com → Click "Admin" → Click "Create Property" → Select "GA4" → Enter your property name → Click "Create".

Step 2: Install GA4 Tracking Code

Method A: Copy the GA4 tracking code and paste it before the </head> tag on your website.
Method B: Use a plugin like "Insert Headers and Footers" for WordPress.
Method C: Use Google Tag Manager (advanced).

Step 3: Track Important Events

GA4 automatically tracks: page_view, scroll, click, file_download, video_start, and session_start. You can also create custom events like: begin_checkout, purchase, generate_lead, sign_up.

Step 4: Set Up Conversions

Go to "Configure" → "Conversions" → Click "New Conversion Event" → Enter the event name (e.g., "purchase") → Save.

Step 5: Link Google Search Console

Connect GA4 with Google Search Console to see which keywords bring traffic. Go to Admin → Property Settings → Search Console → Link.

Step 6: Explore Your Reports

  • Realtime Report: See who is on your site right now
  • Acquisition Report: Where your traffic comes from (Google, social, direct)
  • Engagement Report: Page views, events, conversions
  • Demographics Report: Age, gender, location of users
  • Tech Report: Devices, browsers, screen sizes

Key Metrics to Track

  • Users: Unique visitors
  • Sessions: Total visits
  • Engagement Rate: Percentage of engaged sessions
  • Average Engagement Time: How long users stay
  • Conversions: Completed goals (purchases, signups)
💡 Pro Tip: Set up at least these 5 custom events: scroll (50%), view_item, add_to_cart, begin_checkout, purchase. This gives you a complete view of your sales funnel.
